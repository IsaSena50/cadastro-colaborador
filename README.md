
# Cadastro de Colaboradores - Lojas Brincos e Companhia

Sistema simples de cadastro de novos colaboradores, desenvolvido como atividade da disciplina.

## Sobre o projeto

O sistema é formado por duas páginas:

- **cadastro.html** — formulário onde são preenchidos os dados do colaborador (nome completo, idade, profissão, salário pretendido e experiência anterior).
- **processaCadastro.php** — recebe os dados enviados pelo formulário, armazena em variáveis e exibe uma página de confirmação com todas as informações e uma mensagem personalizada.

## Tecnologias utilizadas

- HTML5
- PHP
- W3.CSS (para estilização)

## Como executar

1. Ter um servidor local com suporte a PHP instalado (exemplo: XAMPP).
2. Colocar os arquivos `cadastro.html` e `processaCadastro.php` dentro da pasta `htdocs` do servidor.
3. Acessar pelo navegador: `http://localhost/nome-da-pasta/cadastro.html`
4. Preencher o formulário e clicar em "Enviar Cadastro" para ver a página de confirmação.

## Campos do formulário

| Campo | Nome do campo (name) |
|---|---|
| Nome completo | nome53 |
| Idade | idade53 |
| Profissão | profissao53 |
| Salário pretendido | salario5315 |
| Experiência anterior | experiencia15 |
